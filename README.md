# 포켓몬 수학

수업용 수학 학습 게임입니다.

게임 실행: https://lo4lolo.github.io/pokemon-math/

## 구글 사이트 삽입
페이지 → 전체 페이지 삽입 → URL에 위 게임 주소를 입력 → 삽입 → 게시.

## 업데이트
로컬 원본 프로젝트에서 `_src`를 수정하고 `python _src/build.py`를 실행합니다. 생성된 `포켓몬 수학.html`을 이 저장소의 `index.html`로 교체하고 커밋합니다. GitHub Pages는 `main` 브랜치 루트에서 게시합니다. `.nojekyll`은 유지합니다.

이 저장소는 실행 파일 배포용입니다. 편집용 원본과 내부 인수인계 문서는 별도 로컬 프로젝트 폴더에서 관리합니다.

학생 기록은 브라우저에 저장됩니다. 기존 파일 실행 화면에서 기록을 옮길 때는 저장 코드를 내보낸 뒤 새 주소에서 불러오세요. 삽입 환경에서 자동 저장이 차단되면 게임의 저장 코드 기능을 사용하세요.

공개 정적 웹앱이므로 교사 화면 비밀번호와 학년 코드는 서버 인증 수단이 아닙니다.

수업용 비영리 팬 제작 학습 도구입니다. 포켓몬 관련 이름·그림의 권리는 각 권리자에게 있으며, 이 저장소가 해당 권리에 대한 라이선스를 부여하지 않습니다.
